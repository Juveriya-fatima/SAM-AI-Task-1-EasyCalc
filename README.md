# EasyCalc 🧮

**EasyCalc** is a simple and user-friendly calculator project developed as part of the **SAM AI Technologies Python Programming Internship**.

The project includes a basic Python calculator and a web-based calculator with a colorful, user-friendly interface.

## ✨ Features

* Addition, subtraction, multiplication, and division
* Percentage calculations
* Decimal number support
* Positive and negative number handling
* Clear and delete buttons
* Division-by-zero error handling
* Attractive and user-friendly interface

## 🛠️ Technologies Used

* **Python** — Basic calculator implementation
* **HTML** — Structure of the web interface
* **CSS** — Styling and design
* **JavaScript** — Calculator functionality

## 📂 Project Structure

```text
Task_1_Calculator/
├── README.md
├── calculator.py
└── calculator_gui/
    ├── index.html
    ├── style.css
    └── script.js
```

## 🐍 Python Calculator

The `calculator.py` file contains the **basic version of the calculator**.

It performs arithmetic operations through the terminal by accepting numbers and an operator from the user.

### Run the Python Calculator

Open the terminal in the `Task_1_Calculator` directory and execute:

```bash
python calculator.py
```

## 🌐 Web-Based Calculator

The `calculator_gui` folder contains the web-based version of EasyCalc.

* `index.html` defines the calculator's structure.
* `style.css` controls its appearance.
* `script.js` handles button interactions and calculations.

### Run the Web Calculator

1. Open the `calculator_gui` folder.
2. Open `index.html` in your web browser.
3. Start performing calculations!

You can also open the project in Visual Studio Code and use the Live Server extension.

## 🎯 Project Objective

The objective of this project is to practise programming fundamentals, implement arithmetic operations, handle user input, and create a simple graphical interface for a calculator.
